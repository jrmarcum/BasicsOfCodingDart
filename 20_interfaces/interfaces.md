#### Note: Dart uses `abstract class` to define interfaces and `implements` for explicit implementation. Go uses implicit interface satisfaction (any type with matching methods automatically satisfies an interface), while Dart requires `implements` to be declared explicitly. `dart:math` provides `pi` (equivalent to Go's `math.Pi`).
