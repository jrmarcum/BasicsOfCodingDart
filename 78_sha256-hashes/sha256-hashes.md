#### Note: Dart's standard library does not include SHA256. This lesson requires the external `package:crypto` package. Add `crypto: ^3.0.0` to your `pubspec.yaml` dependencies and run `dart pub get` before running.
___
##### Run Command:

`$ dart run sha256-hashes.dart`
