#### Note: Dart's `Map` preserves insertion order, so key/value pairs always print in the order they were added. Go's maps have non-deterministic iteration order. Dart maps print in the form `{k1: v1, k2: v2}` rather than Go's `map[k1:v1 k2:v2]`.

___

##### Run Command:

`$ dart run maps.dart`

##### Results:

`map: {k1: 7, k2: 13}`
`v1:  7`
`len: 2`
`map: {k1: 7}`
`prs: false`
`map: {foo: 1, bar: 2}`
