#### Note: In Dart, `main(List<String> args)` receives only the user-supplied arguments — the program name is not included in `args`, unlike Go's `os.Args`.
___
##### Run Command:

`$ dart run command-line-arguments.dart a b c d`

##### Results:

`[command-line-arguments.dart, a, b, c, d]`
`[a, b, c, d]`
`c`
