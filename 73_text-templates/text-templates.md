#### Note: Dart has no built-in text/template package equivalent to Go's `text/template`. This example demonstrates equivalent substitution patterns using Dart string interpolation and helper functions with `replaceAll`.
___
##### Run Command:

`$ dart run text-templates.dart`

##### Results:

`Value: some text`
`Value: 5`
`Value: [Go, Rust, C++, C#]`
`Name: Jane Doe`
`Name: Mickey Mouse`
`yes `
`no `
`Range: Go Rust C++ C# `
